## 📖 Project Overview

Welcome to my portfolio project! This repository demonstrates an end-to-end, production-grade data engineering and business intelligence solution built entirely using **Microsoft SQL Server**. 

By applying modern cloud design frameworks like the **Medallion Architecture** to a relational database engine, this project bridges the gap between raw data infrastructure and corporate strategy to deliver actionable, real-time business insights.

---

## 🏗️ Data Architecture Framework

The platform implements a multi-tier Medallion Architecture to progressively refine raw operational data into high-value business insights:

*   **🥉 Bronze Layer (Ingestion):** Lands raw CSV datasets extracted from disparate ERP and CRM source systems directly into SQL Server tables without modification to protect data lineage.
*   **🥈 Silver Layer (Cleansing):** Automates data deduplication, schema standardization, null-value handling, type-casting, and quality validation to establish an enterprise single source of truth.
*   **🥇 Gold Layer (Presentation):** Models refined data into an analytical **Star Schema** (Fact and Dimension tables) optimized for low-latency business intelligence queries and corporate reporting.

## 🚀 Key Engineering & Analytics Features

*   **Multi-Source System Integration:** Successfully blends fragmented operational data ecosystems (ERP sales records and CRM customer profiles) into a unified database environment.
*   **End-to-End ELT Pipelines:** Engineered automated T-SQL transformation scripts to migrate data seamlessly across data layers.
*   **Advanced Data Modeling:** Implements professional dimensional modeling optimized specifically for cross-functional business analysis.
*   **SQL Analytics Engine:** Built robust SQL analytical queries to uncover key business metrics regarding customer behaviors, sales trajectories, and product velocity.
